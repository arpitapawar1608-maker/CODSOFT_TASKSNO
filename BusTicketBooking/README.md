# Cloud Bus Ticket Booking System

## Project Description

A cloud-hosted web application for online bus ticket booking.
Users can search bus routes, reserve seats, and manage their bookings securely.

## Features

- User registration and login
- JWT-based authentication
- Search buses by source and destination
- Seat reservation
- Booking management
- Secure database storage
- Cloud database support
- Responsive web interface

## Technology Stack

### Backend
- FastAPI
- SQLAlchemy
- Python

### Frontend
- HTML5
- CSS3
- Bootstrap
- JavaScript

### Database
- SQLite (Development)
- PostgreSQL (Cloud Deployment)
